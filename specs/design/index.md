# pyobs-weather: design index

## Status

Meta/index doc, not a feature doc itself. Points at each feature's own design doc and collects
ideas that haven't been fleshed out into one yet.

## How this works

Each non-trivial feature gets its own `FEATURE_NAME.md` under `specs/design/`, following the shape
the sibling repos already use: **Status** (one-paragraph current state, updated as work progresses)
→ **Motivation** → **Current state** (what's true in the codebase before this feature) → **Design**
→ **Open questions** → **Work Plan** (checkboxes). An idea starts as a one-line bullet under
**Ideas** below; when someone's ready to work on it, it's promoted to its own doc and linked from
**Feature docs**.
